This is the living technical reference for the current hardware generation.
It describes the intended architecture and records important design limits, but
it is not a declaration that the hardware is ready for fabrication or use.

The system/backplane is designed for 24–48 V nominal input and six carrier
slots. The current SW3538 carrier limits the first population to 24 V nominal,
30 V maximum input. A second-generation carrier is required for 48 V operation;
the future 240 W-per-slot goal and full-system ratings still require qualification.

Use the version selector in the top navigation to switch between this moving
reference and immutable release documentation when those versions become
available.
